# Сайт храма Александра Невского — п. Усть-Абакан

Простой статический сайт православного храма.

**Без сервера. Без базы данных. Без сборки. Без Node.js, npm, Next.js, Prisma, Bun.**

Просто откройте `index.html` в браузере — и сайт работает.

---

## 📁 Файлы проекта

```
index.html       ← главная страница
style.css        ← стили (православный дизайн: крем/вино/золото)
script.js        ← логика (меню, новости, поиск, галерея, пагинация)

README.md        ← этот файл (инструкция)
.nojekyll        ← важный файл для GitHub Pages
images/          ← папка с фотографиями
    hero/        ← главное фото храма
    news/        ← фото новостей
    gallery/     ← фотоальбом
    clergy/      ← фото духовенства
    about/       ← фото раздела «О храме»
    og/          ← превью для соцсетей
```

## 🚀 Как опубликовать на GitHub Pages

1. Создайте репозиторий на GitHub (например, `prihod`)
2. Загрузите все файлы в корень репозитория
3. Settings → Pages → Source: **Deploy from a branch** → Branch: **main** → /(root) → Save
4. Через 1-2 минуты сайт доступен по адресу:
   ```
   https://<ваше-имя>.github.io/<имя-репозитория>/
   ```

## 📰 Как добавить новость

Откройте файл **`news.js`**. В начале файла — подробная инструкция.

Кратко:
1. Положите фото в `images/news/` (например, `news-005.png`)
2. Откройте `news.js`
3. Скопируйте готовый блок новости (от `{` до `}`)
4. Вставьте его в начало списка
5. Замените текст:
   - `date` — дата (например, `"15 мая 2026"`)
   - `title` — заголовок
   - `images` — **фотографии** (можно одну или несколько!)
   - `excerpt` — краткий текст
   - `content` — полный текст (между обратными кавычками `` `...` ``)
6. Сохраните файл
7. Загрузите на GitHub

### 📷 Несколько фотографий в одной новости

Можно добавить **1, 2, 5, 10 и больше** фотографий. Используйте поле `images` (массив):

```js
{
  date: "15 мая 2026",
  title: "Праздник в храме",
  images: [
    "images/news/news-005.png",
    "images/news/news-006.png",
    "images/news/news-007.png",
    "images/news/news-008.png"
  ],
  excerpt: "Краткое описание...",
  content: `Полный текст...`
}
```

- На главной странице показывается **первая** фотография
- На странице новости все фотографии отображаются **мини-галереей**
- При клике на любую фотографию она открывается **крупно** (лайтбокс)
- Можно листать фотографии стрелками ← →

### Совместимость со старым форматом

Старый формат с одной фотографией тоже работает:
```js
image: "images/news/news-001.png"
```
Если указать и `image`, и `images` — фото из `image` добавится первым.

После добавления:
- ✅ Новость автоматически становится первой
- ✅ Пагинация пересчитывается (9 новостей на страницу)
- ✅ Архив обновляется по годам
- ✅ Поиск находит новую новость
- ✅ Страница «Читать больше» создаётся автоматически
- ✅ Мини-галерея фотографий создаётся автоматически
